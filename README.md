# Kyle Ross Personal Website

Static interactive portfolio site for Kyle E. Ross.

## Stack

- HTML
- CSS
- JavaScript
- No backend
- No database
- GitHub Pages ready

## Features

- Dark professional dashboard design
- Accomplishment accordion cards
- Category filters
- Metrics-focused hero section
- Resume view/download links
- Contact section placeholders
- Mobile-friendly layout

## File Layout

```text
kyle-ross-personal-website/
├── index.html
├── styles.css
├── script.js
├── README.md
└── Kyle.Ross.Resume1.1.pdf
```

## Local Preview

Open `index.html` directly in a browser, or run a simple static server from this folder.

## Resume Setup

Add your resume PDF to this folder with this exact filename:

```text
Kyle.Ross.Resume1.1.pdf
```

The View Resume and Download Resume buttons will work after that file is added.

## Contact Setup

Update the placeholders in `index.html`:

- `your.email@example.com`
- LinkedIn link
- GitHub Pages link

## GitHub Pages Publishing

1. Create a GitHub repository.
2. Upload these files to the repository root.
3. In GitHub, go to Settings > Pages.
4. Set the source to deploy from the main branch root.
5. Save and use the generated GitHub Pages URL.
